에이전트를 여러 개 돌리면 코드는 빨리 나오는데, 검토하고 결정하는 제가 병목이 됩니다.  
지난 영상의 세 계층(매니저 에이전트, 코디네이터 에이전트, 코딩 에이전트) 중 가운데 코디네이터 계층을 제가 실제로 어떻게 쓰는지 정리했습니다.  
그리고 제가 쓰는 Paseo 코디네이터 보드 플러그인을 공유합니다.  
  
이번 영상에서 다룬 것  
\- 매니저 에이전트는 바깥(슬랙, 메일, GitHub 이슈, 티켓)에서 일감을 물어오고, 코디네이터는 그 일을 어느 프로젝트, 어느 세션, 어떤 모델에 맡길지 정합니다  
\- 작업 난이도를 A부터 D까지 나눈 배정표로 모델 고르기도 에이전트에게 맡깁니다  
\- 계정별 남은 사용량과 기기별 여유를 보고 작업을 나눠 줍니다  
\- 사람은 보드의 "내 결정" 카드만 보고 결정합니다  
  
🧩 Paseo 코디네이터 보드 플러그인 설치  
Paseo 0.16.2 이상에서 Settings → Plugins → Enable plugins를 켜고, 세션을 실행할 컴퓨터의 터미널에서 입력하세요.  
paseo plugin install devbrother2024/coordinator-board  
설치 확인: paseo plugin ls coordinator-board  
  
플러그인은 계속 업데이트할 예정입니다. 위 명령으로 설치하면 항상 최신 버전을 받고, 이미 설치하셨다면 아래 명령으로 최신 버전으로 올릴 수 있어요.  
업데이트: paseo plugin update coordinator-board  
  
저 혼자 쓰던 보드를 급하게 범용으로 고쳐서 아직 다듬지 못한 부분이 있습니다. 자유롭게 커스터마이징해서 쓰시고, 버그는 아래 저장소 이슈로 알려 주세요.  
  
📌 참고하실 점  
\- 작업 등급과 모델 배정표는 제 작업 기준으로 정한 예시입니다. 보드 설정에서 등급별 모델과 effort를 바꿀 수 있어요  
\- Paseo가 아닌 Orca, Herdr 같은 도구도 코디네이터용 세션을 하나 두면 같은 방식으로 쓸 수 있습니다  
\- 모든 계층이 모두에게 필요한 건 아닙니다. 코딩 에이전트를 동시에 여러 개(5개, 10개 이상) 돌린다면 코디네이터 계층부터 두는 걸 추천합니다
